## 1. Glossary of Terms & Concepts

### Indian Railways Domain Terminology

- **Telemetry**: Real-time transmission of locomotive telemetry packets (GPS latitude, longitude, bearing heading, instantaneous speed, and delay) from track to server.
- **RTIS (Real-Time Train Information System)**: Satellite-linked hardware receiver device installed directly inside locomotive cabs in collaboration with ISRO (Indian Space Research Organisation) to provide continuous GPS pings without human driver intervention.
- **PNR (Passenger Name Record)**: A 10-digit unique primary key generated by the Indian Railways CRIS (Centre for Railway Information Systems) database representing a passenger's reservation itinerary.
- **PRS (Passenger Reservation System)**: The computerized booking and inventory network governing all reserved passenger coaches across Indian Railways.
- **Permanent Way (P-Way)**: The physical track structure consisting of steel rails, concrete sleepers (ties), ballast bed, and underlying earth formation over which trains run.
- **Block Section**: An operational railway track partition between two consecutive block stations where only a single train is permitted to enter at any one time to prevent rear-end collisions.
- **Rake**: A complete, ordered physical sequence of coupled rolling stock consisting of the electric/diesel locomotive, passenger carriages (AC and non-AC), pantry car, and power cars.
- **WAP-7**: Wide-gauge AC Passenger class-7 high-horsepower (6,350 HP) electric locomotive widely used on Rajdhani, Shatabdi, and Superfast express trains in India.
- **EOG (End-On Generation)**: Power generator cars situated at both ends of modern LHB (Linke Hofmann Busch) rakes that supply electricity for coach air-conditioning, lights, and passenger amenities.
- **3-Aspect Signaling**: Operational color-light signal convention:
  - 🟢 **Green (Line Clear)**: On-time or minor delay ($\le 5\text{ mins}$).
  - 🟡 **Amber (Caution)**: Moderate operational delay ($5\text{--}25\text{ mins}$).
  - 🔴 **Red (Danger / Stopped)**: Significant delay ($> 25\text{ mins}$) or halted at signal.
- **Berth Bay**: An 8-berth transverse and longitudinal compartment bay in Sleeper (SL) and 3-Tier AC (3A) coaches comprising Lower Berth (LB), Middle Berth (MB), Upper Berth (UB), Side Lower (SL), and Side Upper (SU).
- **Telescopic Distance Pricing**: A progressive pricing structure where the per-kilometer fare rate decreases systematically as the total distance of travel increases.
- **Tatkal Quota**: An emergency reservation quota released online at 10:00 AM (AC) and 11:00 AM (Non-AC) one day prior to train origin departure with premium surcharge.
- **Chart Preparation**: A crucial operational milestone occurring 4 hours prior to train origin departure where waitlists (WL/RAC) are finalized, seat allocations freeze, and physical conductor charts are published.
- **TSR (Temporary Speed Restriction)**: Caution order imposed by track engineering departments requiring locomotives to slow down over bridge repair or track renewal sections.

### Frontend & Software Engineering Terminology

- **SPA (Single-Page Application)**: A web application architecture that renders dynamically without requiring full browser page reloads when changing routes or views.
- **Deep Linking / URL State**: Synchronizing application state directly into URL query parameters (`?tab=live&train=12952`) enabling bookmarking, direct sharing, and browser back/forward history navigation.
- **Context API**: React's native mechanism for sharing global state and actions across the entire component tree without passing props through intermediate components ("prop drilling").
- **Zustand**: A lightweight, fast, hook-based state management library built on an external store subscription model with zero boilerplate.
- **`persist` Middleware**: A Zustand store enhancement that automatically serializes state changes to browser `localStorage` and hydrates them back on application reload.
- **`gsap.quickTo`**: GreenSock Animation Platform utility function that creates pre-allocated, high-speed setter functions for numerical CSS properties, executing butter-smooth animations with zero garbage collection overhead.
- **`gsap.ticker`**: A centralized, high-performance animation clock running on `requestAnimationFrame` that synchronizes canvas rendering loops and pauses when tabs lose focus.
- **Web Audio API**: Browser-native digital audio synthesis system that constructs an audio graph of nodes (`AudioContext`, `OscillatorNode`, `GainNode`) to synthesize sound waves mathematically without external audio files.
- **Web Speech API**: Browser-native text-to-speech voice interface (`SpeechSynthesisUtterance`) that vocalizes station announcements in multiple regional languages.
- **3D Perspective Tilt**: A CSS 3D transform technique that calculates the cursor's $(x, y)$ coordinate relative to an element's center point and maps it to `rotateX` and `rotateY` degrees under `perspective: 1000px`.
- **Modulus-11 Algorithm**: The mathematical checksum verification formula used to validate authentic 10-digit PNR ticket numbers.
- **3NF (Third Normal Form)**: Relational database normalization standard requiring that every non-key attribute must depend directly on the primary key, the whole key, and nothing but the key ($X \to Y$).

## 2. Root Layout & Page Shell

### `app/layout.js`
- **What it does**: Defines the HTML document root structure, loads global stylesheets (`globals.css`, `leaflet.css`), sets up web fonts (`JetBrains Mono`, `Plus Jakarta Sans`), injects the theme script to prevent dark/light theme flickering (FOUC), and wraps the application inside `ThemeProvider`, `AppProvider`, and `<CustomCursor />`.
- **How it does it**: Employs Next.js 14 Root Layout conventions. Renders `<head>` with preconnect font links and an inline JavaScript snippet in `dangerouslySetInnerHTML` that immediately checks `localStorage.getItem('railsync_theme')` or the URL query `?theme=dark` before HTML body paint.
- **What functions it calls**:
  - `localStorage.getItem('railsync_theme')` (in inline `<script>`)
  - Mounts `<CustomCursor />`, `<ThemeProvider>`, and `<AppProvider>`.
- **Props**: Receives `{ children }` representing the active route content.

---

### `app/page.js`
- **What it does**: Serves as the primary client-side Single-Page Application (SPA) orchestrator. Handles deep-linked navigation between 7 operational views (`home`, `search`, `live`, `station-board`, `pnr`, `fare-calculator`, `dashboard`), mounts global slide-over drawers, renders `<SignalField />` background canvas, and tracks the active train number.
- **How it does it**:
  - Manages `activeTab` and `activeTrainNumber` state.
  - Subscribes to window `popstate` events to sync URL query parameters (`?tab=...&train=...`) with browser back and forward history buttons.
  - Updates the browser URL bar smoothly using `window.history.pushState`.
- **What functions it calls**:
  - `handleTabChange(tab, trainNum)`: Updates state and calls `window.history.pushState`.
  - `handleTrackTrain(trainNumber)`: Sets active train, switches active tab to `'live'`, and smooth-scrolls to page top.
  - Mounts `<Navbar>`, `<SignalField>`, `<CartDrawer>`, `<EmergencyDrawer>`, `<ToastContainer>`, and `<ApiKeyModal>`.

## 4. Interactive Motion, Canvas & Physics

### `components/CustomCursor.js`
- **What it does**: Dual-layer custom mouse cursor featuring an instant 6px center dot and a smooth trailing 36px ring.
- **How it does it**:
  - Uses `gsap.quickTo` for spring dampening of ring coordinates $(x, y)$.
  - Uses `e.target.closest('[data-cursor]')` to detect contextual targets.
  - When hovering elements with `data-cursor="TEXT"`, morphs into an elongated pill showing the text string.
  - Automatically disables on touchscreens via `window.matchMedia('(pointer: fine)')`.
- **What functions it calls**:
  - `gsap.quickTo(ring, 'x', { duration: 0.35, ease: 'power2.out' })`
  - `gsap.quickTo(ring, 'y', { duration: 0.35, ease: 'power2.out' })`
  - `gsap.to(ring, { width: 'auto', height: '28px', borderRadius: '9999px' })`

---

### `components/SignalField.js`
- **What it does**: Full-viewport HTML5 Canvas background particle system simulating electrical railway track signals.
- **How it does it**:
  - Spawns 40 particles with gentle velocities bouncing off viewport bounds.
  - Draws glowing connective lines between particles closer than 130px.
  - Magnetizes particles toward cursor coordinates within 165px.
  - Runs on `gsap.ticker` and pauses drawing when the tab is hidden via `document.addEventListener('visibilitychange')`.
- **What functions it calls**:
  - `gsap.ticker.add(render)` and `gsap.ticker.remove(render)`
  - Canvas 2D Context: `ctx.arc`, `ctx.lineTo`, `ctx.stroke`, `ctx.fill`.

---

### `hooks/useTiltCard.js`
- **What it does**: Custom React hook delivering 3D perspective tilt to interactive cards.
- **How it does it**:
  - Computes mouse position relative to the card's bounding rectangle:
    $$\text{relX} = \frac{e.\text{clientX} - \text{rect.left}}{\text{rect.width}} - 0.5$$
    $$\text{relY} = \frac{e.\text{clientY} - \text{rect.top}}{\text{rect.height}} - 0.5$$
  - Maps $(\text{relX}, \text{relY}) \to (\text{rotateY}, -\text{rotateX})$ within $\pm 10^\circ$.
  - Applies `gsap.quickTo` for dampening and resets rotations to zero on mouse leave.
- **Returns**: `{ ref, onMouseMove, onMouseLeave }`.

---

### `components/ScrollFeatures.js`
- **What it does**: Provides real-time railway telemetry scrolling capabilities across the application:
  1. **Top Railway Track Scroll Progress Line**: Fixed at the very top of the viewport ($3\text{px}$ height) with an animated electric yellow gradient line tracking reading depth.
  2. **Floating "Scroll to Top" Signal Button**: An interactive station yellow floating action button that fades in once scrolled down past $250\text{px}$, displaying live scroll percentage and triggering smooth animated scroll-to-top on click.
- **How it does it**:
  - Attaches a passive `scroll` listener to `window`.
  - Calculates dynamic scroll progress:
    $$\text{Progress} = \frac{\text{window.scrollY}}{\text{scrollHeight} - \text{clientHeight}} \times 100$$
  - Tags the floating button with `data-cursor="TOP"` so the cursor follower morphs into a contextual pill.
- **What functions it calls**:
  - `window.scrollTo({ top: 0, behavior: 'smooth' })`.

## 8. Hardware & Audio Subsystems

### `lib/audio-chime.js`
- **What it does**: Hardware audio synthesizer utilizing the browser's native Web Audio API.
- **How it does it**:
  1. Instantiates a shared `window.AudioContext` or `window.webkitAudioContext`.
  2. Resumes audio context if in `suspended` state (browser autoplay compliance).
  3. Chains 4 sequential `OscillatorNode` tones with exponential decay curves:
     - Tone 1: $392.00\text{ Hz}$ ($G_4$) at $+0.00\text{s}$
     - Tone 2: $523.25\text{ Hz}$ ($C_5$) at $+0.35\text{s}$
     - Tone 3: $587.33\text{ Hz}$ ($D_5$) at $+0.70\text{s}$
     - Tone 4: $783.99\text{ Hz}$ ($G_5$) at $+1.05\text{s}$
- **Exports**: `playRailwayChime()`.
