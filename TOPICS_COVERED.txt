[MODULE 1-6] HTML5, SEMANTIC WEB, CSS3, & RESPONSIVE DESIGN
--------------------------------------------------------------------------------
• Curriculum Topics:
  - HTML5 structure, semantic tags, accessibility basics
  - CSS3 fundamentals, Box Model, Flexbox, Grid
  - Responsive design, media queries, mobile-first layouts

• How RailSync Covers Them:
  1. Semantic HTML Structure:
     - Uses semantic tags across all views: <header>, <nav>, <main>, <section>,
       <article>, <footer>, <aside>, <time>, <figure>.
     - Files: app/layout.js, app/page.js, components/Navbar.js, components/HomePage.js

  2. Accessibility (a11y) & Standards:
     - Form inputs paired with descriptive placeholders, labels, and aria attributes.
     - Accessible icon buttons with aria-labels (theme toggle, sound toggle, menu).
     - Strict color-contrast ratios adhering to railway high-contrast standards.
     - Files: components/Navbar.js, components/ApiKeyModal.js

  3. CSS3 Fundamentals & Box Model:
     - Custom CSS variables defined in app/globals.css for dynamic dual-theme tokens
       (--station-yellow, --bg-canvas, --surface-card, --border-rail).
     - Custom borders, padding/margin spacing scales, and railway-style shadows.
     - Files: app/globals.css, tailwind.config.js

  4. Flexbox & CSS Grid Systems:
     - Flexbox: Navigation bars, telemetry HUDs, status badges, and button rows
       (e.g., flex items-center justify-between gap-4).
     - CSS Grid: Multi-column station boards, 8-berth compartment bay layout,
       train rake coach layout, and metric stat cards.
     - Files: components/BerthMap.js, components/CoachLayout.js, components/HomePage.js

  5. Responsive & Mobile-First Design:
     - Fully responsive across mobile, tablet, and widescreen viewports using
       Tailwind utility breakpoints (sm:, md:, lg:, xl:).
     - Collapsible mobile navigation drawer with backdrop blur.
     - Multi-tier stacking: 1-column on mobile -> 2/3 columns on desktop.
     - Files: components/Navbar.js, components/LiveTracker.js, components/SearchSection.js

[MODULE 43-48] FULL-STACK SERVERLESS API ROUTES & BACKEND ARCHITECTURE
--------------------------------------------------------------------------------
• Serverless Route Handlers:
  - Six RESTful Next.js backend API endpoints built inside app/api/*:
    1. /api/live — Live GPS coordinates, speed, delay, and station telemetry.
    2. /api/pnr — 10-digit PNR reservation status, chart preparation, passenger berths.
    3. /api/station-board — Real-time platform arrivals and departures (2h, 4h, 8h).
    4. /api/search — Train search between stations or direct by train number.
    5. /api/stations — Fuzzy autocomplete search across 7,300+ Indian stations.
    6. /api/config — Runtime RailKit API key status, validation, and session linking.
  - HTTP request handling via Next.js NextResponse.json() with appropriate HTTP
    status codes (200 OK, 400 Bad Request, 500 Internal Server Error).
  - Query parameter extraction using new URL(request.url).searchParams.
  - Server-side API key protection and proxying to external railway endpoints.
  - Files: app/api/**/route.js


[MODULE 49-54] GIS MAPPING, WEB AUDIO SYNTHESIS & DOMAIN ENGINEERING
--------------------------------------------------------------------------------
• Interactive GIS Mapping (Leaflet.js):
  - Dynamic client-side dynamic() import with SSR disabled ({ ssr: false }).
  - OpenStreetMap & CartoDB tile layers rendered over custom canvas.
  - Custom HTML/SVG map markers and coordinate polyline track corridors.
  - Mathematical bearing and rotation calculations for directional locomotive markers.
  - Files: components/TrackMap.js, components/LiveTracker.js

• Web Audio API Synthesis:
  - Zero external MP3/audio files needed.
  - Synthesizes the authentic 4-tone Indian Railways platform announcement chime:
    G4 (392.00 Hz) ➔ C5 (523.25 Hz) ➔ D5 (587.33 Hz) ➔ G5 (783.99 Hz).
  - Uses AudioContext, OscillatorNode (sine waves), and GainNode (attack/exponential decay bell envelopes).
  - Files: lib/audio-chime.js

• Indian Railways Domain & Algorithmic Logic:
  - 8-Berth Compartment Bay Math: Modular arithmetic calculating bay index
    and berth positions (Lower Berth, Middle, Upper, Side Lower, Side Upper).
  - Train Rake Composition Engine: Complete locomotive-to-guard sequence
    (WAP-7, EOG, Pantry, AC 1st, 2nd, 3rd Tier, Sleeper) with dynamic passenger coach glow.
  - 3-Aspect Railway Signaling State Machine:
    🟢 Green (Line Clear, delay < 5 mins)
    🟡 Amber (Caution, delay 5–25 mins)
    🔴 Red (Danger/Severe Delay, delay > 25 mins)
  - Resilient Hybrid Fallback Engine: RapidAPI RailKit proxy with built-in realistic
    fallback simulations for all major Indian train corridors.
  - Files: components/BerthMap.js, components/CoachLayout.js, components/RouteRibbon.js, lib/railkit.js
